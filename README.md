# Digital Marketing Agency

The website is a Vite-powered vanilla HTML, CSS and JavaScript application. Its visual system, canvas space animation and Supabase enquiry form are retained from the static version.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in Chrome.

## Production build

```bash
npm run build
npm run preview
```

Vite writes the optimized production website to `dist/`. The contact form uses a Supabase publishable key and a database policy that allows insert-only submissions.
